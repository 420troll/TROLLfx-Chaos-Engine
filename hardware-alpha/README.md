# TROLLfx Chaos Engine Hardware Alpha 0.1

Standalone original SpellTwister-derived firmware. Do not install on modified analogue hardware without changing the calibration. No boot-time calibration mode or settings writes; factory input calibration is read only. Encoder selects the secondary algorithm; primary waveform retains original Time/Slope/Ratio, CV, mode and sync behaviour. Original trigger outputs retained. Single Follow click resolves after 600 ms, double ignored, triple toggles DSP CPU ring. 16 segments green/yellow/red; full-ring red flashes for callback overruns or detected late starts. Measured load is DSP callback occupancy only, not whole-system CPU load. Output LEDs use logical 16-bit amplitudes, not reduced PWM compare. Original waveform tables may not reach logical endpoints.

Ring indices clockwise from bottom, zero based:
0 quadrature; 1 cross phase; 2 wavefold; 3 harmonic; 4 logistic map; 5 Lorenz; 6 Rossler; 7 smooth random; 8 phase offset; 9 double frequency; 10 half frequency; 11 amplitude modulation; 12 harmonic FM; 13 frequency modulation; 14 sample and hold; 15 XOR. Attractor math is decimated and provisional. Primary remains original generator, not a second attractor coordinate. No claim of raster pattern generation. Original upstream 22 us DSP timer and 11-bit PWM at system clock/2048 retained.

Temporary nominal 0.05–0.95 V guarded range uses measured diagnostic midpoint and slope on three channels, B secondary copied provisionally from B primary. This is NOT a hardware voltage limiter. Startup/reset/firmware failure can produce out-of-range voltages; keep all video inputs disconnected during boot, reset, flashing and initial bench testing. Original bipolar hardware remains. Trigger jacks are not converted. Verify actual load voltage and ripple before patching. Do not connect B secondary without its own measurement.

Serial 115200: DC 0, DC 25, DC 50, DC 75, DC 100 sets all outputs to static logical levels; RUN resumes standalone operation; INFO reports DSP load and latest deadline fault. DC 0/100 correspond to guarded 0.05/0.95 V targets, not exact 0/1 V. Disconnect all video gear, use DMM and record all four channels at five levels. Scope startup/transient and PWM ripple when available. Do not patch if any voltage leaves 0–1 V. After calibration, adjust per-channel code limits based on verified measurements.

Build: bash tools/build-hardware-alpha.sh using Arduino CLI and RP2040 core 3.9.5 with original libraries. Confirm UF2 targets flash only and does not overlap the final EEPROM sector (0x10FFF000). Preserve verified original backups and diagnostic UF2. Stage separately, never automatically flash. Source was committed remotely; Arduino compilation and physical tests are not yet verified. Inherited multicore and timing behavior requires on-device profiling.
